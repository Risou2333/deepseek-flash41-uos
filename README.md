# DeepSeek Flash 本地客户端 1.1.0

适配目标：你的 UOS Desktop 20 Pro / 龙芯 3A4000 / MIPS64 小端 / Python 3.7.3。后端只使用 Python 标准库，无需 pip、Docker、Flask 或更换系统 Python。使用现有浏览器，不依赖 .deb 安装。

## 先启动，后在网页配置

1. 解压本包，进入 `deepseek-client` 文件夹，在空白处右键“在终端中打开”。
2. 如果旧客户端仍在运行，先在旧服务终端按 Ctrl+C 停止；不要同时启动两份。
3. 执行：

```bash
bash start.sh
```

4. 浏览器自动打开 `http://127.0.0.1:8765`。如果没有打开，手动输入该地址。
5. 全新使用时，页面显示“首次配置”：填入 DeepSeek API Key、本地访问密码、确认密码，点击保存即可。密码至少 8 位。
6. 已使用过 1.0 的用户直接登录，旧 Key 和历史自动沿用。在左下角“Key 与密码”可以更换 Key 或密码，不必再到终端配置。

**不能直接双击 index.html 当作在线客户端使用。必须先启动本地服务。** 新版会检查服务版本；端口被占用时停止启动，不自动打开旧服务。页面侧栏应显示 `1.1.0`，否则请确认旧服务已退出并刷新浏览器。

运行期间保留终端；Ctrl+C 停止服务。`bash diagnose.sh` 可检查本机 Python 组件，不读取 Key、不调用模型。

可选应用菜单入口：在新程序目录执行 `python3 install-desktop.py`，以后从“DeepSeek 工作助手”打开。移动程序目录后应重新执行；旧菜单入口可能仍指向旧文件夹。

## 针对“有回答但 API 无消耗”的核验流程

不能通过模型自称身份、回答口吻或客户端标题确认底层版本。本版不提供假回答或备用模型；主程序没有模拟接口开关。测试中的模拟只存在于 `tests/`。

1. 登录新版，确认侧栏版本为 1.1.0。
2. 打开“连接与用量诊断”，点击“查询模型与余额”。这会使用本机实际生效的 Key，分别访问官方 `/models` 与 `/user/balance`，显示原始 JSON 结果或错误。
3. 点击“发送一条计费测试”。程序会新建独立对话，使用关闭思考的 `deepseek-flash` 生成一条短回复。这个按钮会真实调用生成接口，可能产生费用，没有后台自动执行。
4. 在回复下查看 token 用量与“调用详情”：包含请求模型、API 实际返回模型、响应 ID、输入/输出/缓存命中 token、结束原因、耗时和本地客户端版本。
5. 用量缺失明确显示“API 未返回”，不会把缺失值冒充为 0；旧版历史没有这些信息，也不会伪造补齐。
6. 如果生成失败，错误会保留在页面，不显示“成功验证”。需要排查时，可提供错误文字或调用详情，不要提供 Key、密码或 config.json。

模型列表和余额成功，仅能证明这些接口可访问，不能证明生成成功。真实调用详情与平台账户记录应结合检查。本次开发没有拿到你的 Key，所以尚未复现或确定你原先“无消耗”的具体原因。

当前 Key 可能来自 `DEEPSEEK_API_KEY` 环境变量，优先于配置文件，登录后的状态行会说明来源。如果存在该变量，网页会拒绝修改 Key，并提示停止服务、取消该变量后重启，以免“新 Key 保存了但仍在使用旧 Key”。正常网页配置不需要设置此变量。

## Flash 4.1 与功能设置

截至 2026-09-10，官方将 `deepseek-flash` 映射为 DeepSeek-V4.1-Flash。本版固定使用这个官方请求名，不自行构造 `deepseek-4.1-flash`，也不切到 Pro。API 返回字段可能仍是别名；这里保留原值，不把别名改写成内部快照证明。[官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/)

| 功能 | 本版实现 |
|---|---|
| 默认思考 | high；可选关闭、low、high、max |
| 输出上限 | 默认不发送 max_tokens，跟随 API；也可选 8K、16K、32K、64K、128K |
| 回答风格 | 默认没有额外 system 提示词；可在“对话设置”填写自定义指令 |
| 设置保存 | 按对话保存，切换会话恢复；点击发送也保存当前设置 |
| 多轮历史 | 保存用户、回答、图片、思考文本及调用信息；重启后保留 |
| 思考历史 | 可以展开查看；普通聊天下不回传旧思考文本 |
| JSON 输出 | 发送 response_format=json_object，并自动添加 JSON 指令；本地校验是否为 JSON 对象 |
| Markdown | 标题、粗体、代码、项目符号、引用、基础管道表格和 HTTP(S) 链接；不执行模型 HTML |
| 导出 | MD：问答文字及图片名称；JSON：问答、原图、思考及调用元数据，不含 Key |
| 对话管理 | 新建、切换、按标题搜索、重命名、删除、复制回答、继续上一条 |
| 诊断 | 用户手动查询官方模型列表与余额，手动生成一条计费测试 |

思考强度与开关按官方参数发送；思考开启时不附加无效的 temperature 等采样参数。长输出被截断时，以 `finish_reason=length` 标记，保留返回正文，不向正文塞入提示以免破坏 JSON；界面另行提示。[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/) · [Chat Completions 参数](https://api-docs.deepseek.com/api/create-chat-completion/) · [JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)

设置“跟随 API”不代表客户端无限资源：单次返回（思考加正文）仍有 200 万字符保护上限，生成在读取事件时检查 30 分钟时限。较大思考预算和输出长度可能增加耗时与费用，官方默认值和价格后续可能改变。

## 文件与图片

一次最多 6 个附件，其中图片最多 3 张。点击“文件 / 图片”选择多个文件，可以逐项移除、预览。点击发送前的读取与文字提取均在本机；点击发送才上传文字或图片。

| 类型 | 能力与边界 |
|---|---|
| JPEG、PNG、GIF、WebP | 以官方 image_url + Base64 方式交给 Flash 识别；可选择原图/低精度；历史中保留原图供后续追问 |
| TXT、MD、CSV、TSV、JSON、LOG | 提取文本；支持 UTF-8、常见 GB18030、带 BOM 的 UTF-16 |
| DOCX | 提取正文段落及正文表格文字，不保留排版；不包含页眉页脚、批注或图片 |
| XLSX | 按工作表输出单元格地址和已有缓存值；不计算公式，日期可能是序列数 |
| PDF | 使用可选系统 pdftotext 提取前 50 页文字；不含图像；扫描 PDF 请先导出页面图片再作为图片发送 |
| DOC、XLS 等旧格式 | 先在本机另存为 DOCX/XLSX；不直接解析 |

每个文件限 5 MiB；本轮全部图片合计限 5 MiB。单份文字提取限 100000 字符；提问与全部文件文字合计限 120000 字符，还必须落在所选的上下文预算内。超过限制会报错，不自动丢弃材料。PDF 的前 50 页限制会明确显示在提取预览中。

为适应你的电脑，本版客户端限制低于官方接口上限；图片解析是否成功仍由 API 校验，复杂扫描内容不保证识别准确。没有本地 OCR 引擎，没有上传到官方 Files API 的额外文件管理流程。[官方视觉输入文档](https://api-docs.deepseek.com/guides/vision/)

需要文字型 PDF 支持时，可在 UOS 软件源可用的前提下安装：

```bash
sudo apt install poppler-utils
```

不需为其他格式安装 Python 第三方包。文件内容里的指令不应当作你的任务执行；涉及重要数据时核对原件。

## 上下文、保存与停止

本地文字上下文预算可选 48000、96000、192000 字符，默认 96000。选择最新完整问答对，包含本轮文字及自定义指令；超出预算的最早轮次省略但不删历史。界面和调用详情显示省略轮数。带图历史还受 Base64 累计 8 MiB、最多 12 张图片的请求保护预算约束，图片所在问答整体省略。该预算与官方模型 token 上下文上限不是同一概念。

没有工具调用的聊天仅回传用户内容、选中的原图和最终回答，不回传旧思考过程。当前没有联网搜索、自动调用办公软件、向量知识库或 agent 工具执行，这些不因模型支持工具调用而自动具备。

本版一次只生成一个请求。成功回答及 `length` 截断回答成对入库；取消、断流、没有正文或错误时不保存本轮。输入与附件保留，方便手动重试。系统不自动重试付费生成，以免重复计费。

停止按钮设置取消标记，需要等待当前网络读取返回（单次等待超时 90 秒）；不保证瞬间停止上游计费。如果服务端已保存而浏览器恰好断开，先重开会话查看历史，再决定是否重试。

## 数据、密码与升级

默认目录不变：

```text
~/.local/share/deepseek-client/
├── config.json              API Key 与密码哈希
├── history.db               聊天、原图、思考、调用信息
└── history-before-v1.1.db    首次升级表结构前的数据库副本
```

`DEEPSEEK_DATA_DIR` 可指定其他数据目录。升级时新增数据库列，保留旧消息；迁移前制作副本。推荐升级前停止服务并自行备份整个数据目录。自动副本只用于恢复迁移前记录，不会同步后续新聊天；若回滚，应先另存新数据库。

数据目录权限 700，配置/数据库 600；Key、聊天及图片未做磁盘加密，密码使用 PBKDF2 哈希。导出的 JSON 包含材料和图片，分享前自行核对。删库记录不等同于安全擦除磁盘。

网页登录与配置只面向本机 127.0.0.1，Host/Origin 校验保护写入，Cookie 为 HttpOnly/SameSite=Strict，失败登录限速。不要将服务改为局域网或公网开放。Key 提交给本机后端保存，不回填页面，不写入浏览器 localStorage，不含在导出内容中。

更换凭据需要当前本地密码，成功后所有会话登录失效，需要重新登录。忘记本地密码时仍可在停止服务后执行 `python3 app.py --setup` 重新配置（会要求重新填写 Key），历史保留。

## 已验证与尚待验证

见 `VALIDATION.md`。自动测试使用模拟 API 数据，不访问真实付费接口。当前交付环境没有可用测试浏览器，未完成真实浏览器截图与交互验证，也未在你的 MIPS64 / Python 3.7.3 电脑上运行。Python 3.7 语法与标准库使用检查不等于目标机实测。

最低实机验收：启动新版 → 登录/首次配置 → 模型余额查询 → 一条计费测试 → 检查调用详情 → 发图追问 → 刷新查看历史。首次计费测试不要附加工作材料。

遇到 `ssl` / `sqlite3` 导入错误，先运行 `bash diagnose.sh`，从 UOS 软件源修复组件；不要为此替换系统 Python。网络/证书错误请检查系统时间、网络和系统 CA，不要禁用 TLS 验证。API 错误代码会直接显示相应提示。
